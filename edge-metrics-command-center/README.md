# EdgeMetrics Command Center

Real-time observability dashboard concept for monitoring API latency, error budgets, deployments and regional service health.

## Recruiter Signal

- Systems thinking around reliability, SLOs and incident workflows.
- Frontend skill with dense data interfaces and real-time state.
- Backend awareness through event streams, aggregation and operational metrics.

## Suggested Architecture

- React and TypeScript dashboard UI.
- Node.js ingestion API for service events.
- WebSocket stream for live metric updates.
- PostgreSQL tables for incidents, deploys, alerts and service snapshots.
- Background worker for rollups and alert evaluation.

## Core Features

- Service health board with latency, throughput and error rate views.
- SLO burn-rate panel for understanding reliability risk.
- Incident timeline joining deploys, alerts and owner notes.
- Region filters for comparing global API behavior.
- Loading, empty, stale-data and reconnect states.

## Portfolio Story

This project is designed to show that I can build product-grade engineering tools, not just static pages. It highlights data modeling, responsive UI design, API integration and careful UX for high-pressure workflows.
